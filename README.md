# 📖 About Repository

**AI-Powered-Code-Reviewer-using-MERN-Stack** is a full-stack AI-based code review platform that analyzes source code, detects issues, suggests improvements, and helps developers write cleaner and more optimized code.

The application combines the power of Artificial Intelligence with the MERN Stack to provide automated code review workflows for developers, students, and software teams.

Built using modern technologies like React.js, Node.js, Express.js, and AI integrations, the project delivers an interactive developer experience with intelligent code analysis capabilities.

AI-powered code review systems are increasingly used to improve code quality, security, and developer productivity in modern software development workflows. ([IJRPR][1])

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/ERAnkit03/AI-Powered-Code-Reviewer-using-MERN-Stack.git
```

---

## 2️⃣ Move Into Project Folder

```bash
cd AI-Powered-Code-Reviewer-using-MERN-Stack
```

---

# 🔧 Backend Setup

## Install Dependencies

```bash
cd BackEnd

npm install
```

## Configure Environment Variables

Create `.env` file:

```env
PORT=5000

GEMINI_API_KEY=your_gemini_api_key

FRONTEND_URL=http://localhost:5173
```

## Run Backend Server

```bash
npm run dev
```

---

# 🎨 Frontend Setup

## Install Dependencies

```bash
cd Frontend

npm install
```

## Start Frontend

```bash
npm run dev
```

```text
User Inputs Code
        │
        ▼
Frontend Sends Request
        │
        ▼
Backend API Receives Code
        │
        ▼
Gemini AI Processes Code
        │
        ▼
AI Generates Review & Suggestions
        │
        ▼
Frontend Displays Review Output
```
